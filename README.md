## Overview

NetMirror is an open-source Android app inspired by the NetMirror web app. It was rebuilt from scratch after reviewing the original app\'s behavior — with one goal: **user trust through open code and layered security.**

## Features

| Area | What you get |
|------|--------------|
| Privacy-first | No personal data collection, no selling/sharing data |
| Security | Multi-layer validation, tamper protection, HTTPS-only |
| Clean | No intrusive ads, no ad SDKs, no analytics trackers |
| Lightweight | Optimized size, fast startup, minimal permissions |
| Modern UI | Clean interface, smooth navigation |
| Open | 100% open source — audit anything |

## Security

- Multiple security validation layers
- Protection against unauthorized modifications
- Secure network communication (HTTPS)
- Minimal permission usage
- No background data collection
- No hidden trackers or advertising SDKs

## Privacy Promise

This app:

- Does NOT collect personal information
- Does NOT include ad SDKs or analytics trackers
- Does NOT request unnecessary device permissions
- Does NOT sell or share your data

## Getting Started

```bash
git clone https://github.com/the-anonymous-vigilante/Netmirror.git
cd Netmirror
```

Open in Android Studio → Sync Gradle → Run on emulator or device (Android 7.0+).
